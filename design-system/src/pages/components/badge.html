Components

Badge

A 20px pill for state that qualifies something else — never for the thing itself. Badges are labels, not controls: if it responds to a press, it is a button.

Variants

Default Secondary Outline Destructive Ghost Link
secondary
The default choice in practice — "Archived", "Recurring". Quiet metadata.
outline
Classification that must not compete with the row: "Payment", "Guest".
default
Filled primary. Rare — reserve it for something genuinely active.
destructive
A tint, matching the button. Failed imports, expired invites.
ghost / link
Inside dense surfaces where even an outline is too much.

Badges in a row sit next to the title, before the metadata line, and are shrink-0 so a long description truncates instead of squeezing them.

Rules

Do

Keep the text to one or two words, sentence case. A badge that wraps has become a description.

Don't

Use a badge for a balance. Money uses the tone system with its icon and its word — see Patterns → Money.
