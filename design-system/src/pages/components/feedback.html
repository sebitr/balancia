Components

Feedback

Four ways to tell somebody something, ranked by how much they have to care: a toast they can ignore, an alert they should read, a dialog they must answer, and an empty state that hands them the next step.

Empty state

No expenses yet

Add the first expense and Balancia will start working out who owes whom.

Three parts, all required: what is not here, why that is fine, and the button that fixes it. A bare "No data" is never acceptable — the dashed border is a placeholder for content, so it has to suggest what would fill it.

Skeleton

A skeleton takes the shape of the row it replaces, so the layout does not jump when data lands. Never skeleton an amount into a shape wider than the amounts that follow it.

Alert

Rates last updated 3 days ago
Converted totals use the rate stored when each expense was created.
4 of 62 rows could not be imported
Rows 12, 19, 44 and 58 have an amount Balancia could not parse. Download the report to fix and retry.

Alerts belong in the page flow, next to what they describe. They persist; if it can be dismissed and forgotten, it was a toast.

Dialog

Delete this expense?

"Dinner at Trattoria Il Ponte" — €128.40 — will be removed and everyone's balance recalculated. This cannot be undone.

A destructive confirmation names the thing and its amount. "Are you sure?" gives nobody the information they need to be sure. Cancel is on the left and is the safe default.

Toast

Expense added
Dinner at Trattoria Il Ponte · €128.40
Couldn't save
You're offline — this will retry automatically.

Toasts confirm something that already happened. They never carry the only copy of information somebody needs, and they never ask a question — an action that needs an answer is a dialog.
