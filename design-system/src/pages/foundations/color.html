Foundations

Colour

Every colour is an OKLCH token defined in src/app/globals.css and consumed through a semantic name — never a raw value in a component. Light and dark are two sets of the same names; toggle the theme to check both.

Balance semantics

Three tokens carry the only meaning that actually matters in this product. They exist so a balance is legible before anyone reads a number.

--destructive never fills a button. Delete actions use a 10% tint with destructive-coloured text so they read as serious without shouting louder than the primary action on the same screen.

Text on surfaces

--foreground — body copy, amounts, titles
--muted-foreground — section headings, metadata, descriptions
--primary — links and the active nav item
--destructive — field errors and delete affordances

All pairings meet WCAG 2.2 AA on their intended background in both themes. Re-check any new pairing before shipping it — the OKLCH lightness values were chosen for this, not by eye.
