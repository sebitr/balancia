Numerals

Tabular lining figures are enabled globally on html, and .tabular-nums restates it on amount columns. Digits must align down a list or the eye can't scan it.

Amounts arrive from Server Components as decimal strings of minor units and are formatted through Intl.NumberFormat. Never a JavaScript number, never a hand-written currency symbol — the separator, symbol position, and decimal count are all locale decisions.

Rules

Do

Use weight and colour to build hierarchy. Two weights (500, 600) and two text colours cover almost every screen.

Don't

Add a size between the steps above, or set body copy below 14px. The phone is the primary target.
