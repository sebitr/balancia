Balancia

Design system

Balancia is self-hosted shared expense tracking. People open it to answer one question — where do I stand? — so the system optimises for a fast, unambiguous, trustworthy answer on a phone, and for nothing else.

Principles

01 — Money is never ambiguous

Every balance carries three redundant cues: a word (owes / gets back / settled up), an icon, and a colour. The meaning survives greyscale, colour blindness, and a screen reader. Colour alone is never the signal.

02 — Calm, not financial

Deep plum on cream, with coral held back for the one thing to do next. Friendly and trustworthy without reading as banking software — this is a trip with friends, not a ledger review.

03 — Phone first

Content caps at max-w-3xl. Group pages get a fixed bottom bar with Add centred and filled, because recording an expense is the thing people came to do. Safe-area padding is not optional.

04 — Digits line up

Tabular lining figures are on globally via font-feature-settings. Amounts are formatted through Intl from minor units as strings — never JavaScript numbers.
