Patterns

Cloud backup

An owner copies the groups they own to a cloud of their own, encrypted so that neither Balancia's server nor the cloud can read them. The screens carry two burdens the rest of settings does not: a decision that cannot be undone (lose the key, lose the backups) and a process that runs while nobody is looking, which is exactly the kind that fails silently. Both shape what is drawn.

The recovery key comes first

If you lose it. Nobody can open your backups without this key: not you, not us, not your cloud service. There is no reset, so keep it in a password manager.

It is made in the browser and the server is sent only the public half, so the loss warning belongs on this screen and nowhere else in the flow. Continue stays off until a box is ticked and the last six characters are typed back, and says which of the two is missing. The outline and the words under the field both name the characters; neither relies on colour.

Choosing where

State How it is drawn What it says
Available Row on a phone, tile from lg; radio semantics The provider's name, one line of what it is for
Switched off by the administrator Dashed and muted; cannot be picked “Not enabled on this server” over “Ask your administrator.” — the words carry it, not the dimming
Experimental A group of its own, under a plain disclosure Three short facts, no red and no warning triangle: no official interface, the password is kept on this server, it can stop working

Providers are monograms on a neutral tile, not logos: a logo is somebody's trademark and carries rules about colour and clear space, two letters say which provider this is just as well.

Status is an icon and a word

  • Backed up Today, 03:30 · 14 groups · 212 kB ✓ Backed up
  • No changes Nothing changed since the last backup. – No changes
  • Failed Not enough space in Dropbox. ! Failed

Success is neutral ink. Failure uses the destructive token. The money colours — green for owed to you, red for you owe, amber for the payer — never appear here: they mean someone owes someone, and a backup that ran is not that. The accent colours the button, the ring, the switch and a selected chip, never a status.

A failure is never quiet

Reconnect Google Drive
Access was revoked, so backups have stopped.

Four places say it, because a backup is the one feature whose failure the owner will not see by using the app: a banner above the card (with the action under the text, since an absolutely placed action would pinch a 362px column), a “Needs attention” pill on the settings row, every run kept in History with the provider's own words in monospace, and the schedule itself — a revoked connection is not retried until its owner acts, because retrying a revoked token every hour is how an account gets flagged.

What saves, and what asks first

Control Behaviour
Automatic backups switch, Daily/Weekly, backups to keep, the group ticks, receipts Written the moment it is pressed, with no Save button and no toast. Pressing again is the way back. A refusal flicks the control back and says so in an error toast.
Back up now The result stays in the card (progress, then “Backed up just now”), not in a toast. A failed manual run is an error toast and a row in History.
Stop backing up · Create a new recovery key A ConfirmSheet, with the way out named in the reader's words (“Keep backing up”, “Keep my current key”). The only two things here that ask first.

Rules

Do

Put a number beside the cost. “About 38 MB of receipts across 3 groups” is a decision someone can weigh against a quota; “receipts may use storage” is not.

Don't

Promise what was not checked. Restoring a receipt is a manual step today, and the receipts disclaimer says so beside the switch rather than after it has been turned on.
