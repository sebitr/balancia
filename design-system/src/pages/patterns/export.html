Patterns

Export

Balancia's claim is that you can leave. That is only true if leaving produces something usable, so the same data is offered three ways — and the interface says plainly which one is which, rather than presenting three interchangeable buttons.

On a phone

Export

Your data, in a format you can open anywhere. The file is built on this server and sent straight to you.

CSV and Excel hold one row per person per expense, ready to sort and total. JSON is the complete record — every amount exactly as stored — and is the one to keep for an archive.

Receipts are not in these files — download them from each expense.

Above sm the three buttons become a row. Nothing else about the card changes: the explanation is not a tooltip or a help link, because choosing a format is exactly the moment the difference matters.

What each format is for

Format Shape Amounts Use it when
JSON The whole group, nested Integer minor units, as strings Archiving, or moving to another instance
CSV One row per person per expense Major units, e.g. 30.00 A script, or a spreadsheet pivot
Excel Four sheets: expenses, payments, people, balances Numeric cells, summable Sharing a readable summary with the group

The split is deliberate and stated in the copy. JSON is the format that cannot lose a digit; the spreadsheet formats present major units because that is what a spreadsheet can add up. Money never passes through a floating-point number on the way to a cell — the decimal literal the money module produced is written verbatim.

Who can export

  • Owner and member The Export card is shown Yes
  • Guest, via an invitation link No card, and the endpoint answers 404 No

This is not about secrecy — a guest already reads every expense on screen. An invitation link is a bearer token which may be forwarded, and a one-request download of a group's entire financial history is a sharper tool in the wrong hands than the same data read a page at a time. The refusal is a 404 rather than a 403, like every other authorization failure, so nothing is confirmed to someone who should not be asking.

Rules

Do

Say what each format is for, in the same breath as offering it. "CSV, XLSX, JSON" is a file-extension list; "the one to keep for an archive" is a decision someone can actually make.

Don't

Imply the export contains more than it does. Receipts live in storage and are downloaded per expense — saying so is better than letting someone discover it after they have deleted their account.
