Patterns

Settle up

The end of the story. Balancia proposes the fewest transfers that clear the group, phrased as sentences a person can act on — "Jonas pays Amélie €148.60" — not as a matrix anyone has to decode.

Suggested transfers

Two payments clear this currency.
  • JT Jonas pays Amélie Clears Jonas entirely €148.60
  • RS Ravi pays Amélie Clears Ravi entirely €99.40

One card per currency — transfers never cross currencies unless the group is in converted mode. The subtitle says what each payment accomplishes, so the suggestion is auditable rather than magic.

To

Pre-filled with the suggested transfer. A partial payment is fine — the remainder stays owed.

The amount is editable. People pay round numbers and pay in parts, and a system that only accepts the exact suggested figure gets abandoned the first time somebody hands over €150 for a €148.60 debt.

Settled up

A cleared currency says "Settled up" — never "€0.00". Zero is a state, not an amount, and phrasing it removes any doubt about whether the number failed to load.

Rules

Do

Write transfers as full sentences with both names. "Jonas → Amélie" needs a key; "Jonas pays Amélie" does not.

Don't

Present the suggestion as the only option, or block a payment that doesn't match it. Balancia records what people did; it does not instruct them.
