# Put a way in for somebody who already has an account on the homepage's first screen, and in the phone header where there was none

Branch: `feat/homepage-sign-in`

The header's "Sign in" was hidden below 721px, so a phone saw the language
switcher, the GitHub mark and "Create account" and nothing for a returning
reader; the one sign-in link a phone had was the closing section's, a whole
page down. Now the hero carries "Already have an account? Sign in" under its
buttons, and on a phone the header's GitHub mark gives its place to the
sign-in link. Below 440px the wordmark shows its mark alone so the row fits:
on a 360pt phone the row is 328pt wide, the old four items took 330 of them,
and "Se connecter" is 108pt against the GitHub mark's 40.
